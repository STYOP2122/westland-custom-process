# Westland RP Process Branding

ASI-плагин для Windows, который применяет оформление Westland RP к процессу и основному окну игры: меняет заголовок окна, устанавливает иконку и обновляет данные процесса.

## Сборка

Понадобятся Visual Studio с инструментами C++ v145 и Windows SDK. При использовании другого набора инструментов перенастройте проект.

1. Откройте `WestlandRP.sln`.
2. Выберите **Release / Win32**.
3. Соберите проект `WestlandRP`.

Выходной файл — `WestlandRP.asi`; каталог задаётся настройками проекта Visual Studio.

## Настройка

- `WestlandRP/main.cpp` — имя процесса, заголовок окна и применение иконки.
- `WestlandRP/peb.h` — изменение данных процесса.
- `WestlandRP/westland.ico` и `resource.rc` — иконка и ресурсы.

Плагин загружается через ASI Loader. Он использует внутренние структуры процесса Windows, поэтому совместимость нужно проверять на целевой системе и версии игры.
